# 09 MyBatis-Plus 入门、注解与配置

> MP 的定位：**只做增强，不做改变**。MyBatis 该会的还得会，MP 只是把「单表 CRUD」这条流水线自动化了。

## 1. MP 是什么

- 官网 `https://baomidou.com/`，由国内开发者 **baomidou** 创建维护，托管在 **Gitee**（GitHub 有镜像）。
- **不是 MyBatis 的替代品**，是增强工具；也**不是官方插件**，但被 MyBatis 官方文档收录推荐。
- 核心卖点：**「约定大于配置」**，简单配置（甚至不配置）就能完成**单表 CRUD**。
- 支持达梦、人大金仓等国产数据库，中文文档完善。
- 官方最佳实践：**MP 做单表，多表复杂查询回到 MyBatis XML**。

| | MyBatis | MyBatis-Plus |
| --- | --- | --- |
| 单表 CRUD | 每个方法写 SQL | **`BaseMapper` 全给你** |
| 条件查询 | 手写动态 SQL | `Wrapper` 链式构造 |
| Service 层 | 自己写 | `IService` + `ServiceImpl` |
| 分页 | PageHelper / 手写 limit | 分页插件 |
| 学习成本 | 要懂 XML、映射 | 会调 API 即可 |

## 2. 第一个 MyBatis-Plus 程序（Spring Boot 3）

| 步骤 | 内容 |
| --- | --- |
| 1 | 引入 `mybatis-plus-spring-boot3-starter` |
| 2 | 实体类（`@TableName`） |
| 3 | `application.yml` 配数据源 |
| 4 | Mapper 接口 `extends BaseMapper<Car>` |
| 5 | 启动类加 `@MapperScan` |
| 6 | 写测试类跑 CRUD |

### 2.1 依赖

```xml
<dependencies>

    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter</artifactId>
    </dependency>

    <!-- MyBatis-Plus 的 Spring Boot 3 启动器 -->
    <dependency>
        <groupId>com.baomidou</groupId>
        <artifactId>mybatis-plus-spring-boot3-starter</artifactId>
        <version>3.5.11</version>
    </dependency>

    <!-- MySQL 驱动（Spring Boot 3 用 com.mysql:mysql-connector-j） -->
    <dependency>
        <groupId>com.mysql</groupId>
        <artifactId>mysql-connector-j</artifactId>
        <scope>runtime</scope>
    </dependency>

    <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <optional>true</optional>
    </dependency>

    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-test</artifactId>
        <scope>test</scope>
    </dependency>
</dependencies>
```

> **版本对应关系**（很容易踩坑）：
> - Spring Boot 2.x → `mybatis-plus-boot-starter`
> - Spring Boot 3.x → **`mybatis-plus-spring-boot3-starter`**（用错了会启动报 `NoClassDefFoundError: javax/servlet/...` 之类）
> - 分页插件 3.5.9+ 需要额外引入 `mybatis-plus-jsqlparser`（见 [11 篇](11-MP-进阶特性.md)）

### 2.4 Mapper

```java
public interface CarMapper extends BaseMapper<Car> {
}
```

就这一行，`insert`、`deleteById`、`updateById`、`selectById`、`selectList`…… 全部具备。

### 2.5 启动类

```java
@MapperScan(basePackages = {"com.jkweilai.mp.mapper"})
@SpringBootApplication
public class Mp01Application {
    public static void main(String[] args) {
        SpringApplication.run(Mp01Application.class, args);
    }
}
```

> 只写一个 Mapper 接口也可以用 `@Mapper` 注解，但**多个接口时统一用 `@MapperScan`** 更省事。

### 2.6 测试

```java
@SpringBootTest
class Mp01ApplicationTests {

    @Autowired
    private CarMapper carMapper;

    @Test
    void testInsert() {
        Car car = new Car();
        car.setCarNum("999");
        car.setBrand("小米su7");
        car.setGuidePrice(30.00);
        car.setProduceTime("2025-10-11");
        car.setCarType("电车");
        System.out.println("插入" + carMapper.insert(car) + "条记录");
    }

    @Test
    void testDeleteById() {
        System.out.println("删除了" + carMapper.deleteById(7L) + "条记录");
    }

    @Test
    void testUpdateById() {
        Car car = new Car();
        car.setId(8L);
        car.setBrand("小米ultra");
        System.out.println("更新了" + carMapper.updateById(car) + "条记录");
    }

    @Test
    void testSelectById() {
        System.out.println(carMapper.selectById(8L));
    }

    @Test
    void testSelectAll() {
        carMapper.selectList(null).forEach(System.out::println);
        // selectList(null) = 不带任何条件，查全表
    }
}
```

**`BaseMapper` 常用方法速查**

| 方法 | 说明 |
| --- | --- |
| `insert(T)` | 新增，主键自动回填 |
| `deleteById(Serializable)` | 按主键删 |
| `deleteByIds(Collection)` | 批量删（`in`） |
| `deleteByMap(Map)` | 按等值条件删 |
| `delete(Wrapper)` | 按 Wrapper 条件删 |
| `updateById(T)` | 按主键更新（**null 字段不更新**） |
| `update(T, Wrapper)` | 按条件更新 |
| `selectById(Serializable)` | 按主键查 |
| `selectBatchIds(Collection)` | 批量查（`in`） |
| `selectList(Wrapper)` | 条件查列表 |
| `selectCount(Wrapper)` | 条件计数 |
| `selectMaps(Wrapper)` | 返回 `List<Map<String,Object>>` |
| `selectPage(Page, Wrapper)` | 分页（需装插件） |

## 3. 实体类和表是怎么对应上的？（约定大于配置）

`CarMapper` 只继承了 `BaseMapper<Car>`，没有 XML，MP 是怎么知道该操作哪张表的？

1. 通过 `BaseMapper<Car>` 的**泛型**拿到实体类 `Car`；
2. **反射**读类名和字段名；
3. 按下面的**约定**推出表名与列名：

| 约定 | 例子 |
| --- | --- |
| 类名驼峰转下划线 = 表名 | `Car` → `car`；`UserInfo` → `user_info` |
| 属性名驼峰转下划线 = 列名 | `carType` → `car_type` |
| 名字为 `id` 的属性 = 主键 | `private Long id;` |

**不符合约定就得用注解显式指定**（`Car` ↔ `t_car` 就是典型的不符合）。

## 4. 三个核心注解

| 注解 | 作用 |
| --- | --- |
| `@TableName` | 指定**表名** |
| `@TableId` | 指定**主键字段**及其生成策略 |
| `@TableField` | 指定**普通字段**（列名、是否存在、类型处理器等） |

### 4.1 `@TableName`

```java
@Data
@TableName("t_car")
public class Car {
    // ...
}
```

- 也可用于「动态表名」场景：`@TableName(value = "t_car", autoResultMap = true)`。
- **`autoResultMap = true` 是 JSON 类型处理器必须开的开关**（见 [11 篇](11-MP-进阶特性.md)）。

### 4.2 `@TableId`

```java
@TableId(value = "id", type = IdType.AUTO)
private Long id;
```

`IdType` 的 5 种取值：

| 值 | 说明 |
| --- | --- |
| `AUTO` | **数据库自增**，最常见 |
| `ASSIGN_ID`（默认） | MP 生成 **雪花算法** 的 64 位 ID（`Long`/`String`） |
| `ASSIGN_UUID` | 生成 UUID，**主键只能是 String** |
| `INPUT` | 程序员自己手动赋值 |
| `NONE` | 不指定，跟随全局 `id-type` 配置 |

**关于雪花算法（Snowflake）**

- 64 位 = 1 位符号 + 41 位时间戳 + 10 位机器 ID + 12 位序列号 ⇒ 全局唯一、趋势递增、占 8 字节。
- 风险：**时钟回拨**、**机器 ID 不唯一**时可能重复（概率低）。
- **坑**：一旦指定 `type = IdType.ASSIGN_ID`，**即使数据库主键是 `auto_increment`，也会用雪花算法生成 ID**，自增失效。
- 全局默认是 `ASSIGN_ID`，用自增表时要么在每个实体加 `@TableId(type = IdType.AUTO)`，要么全局配 `id-type: auto`。

### 4.3 `@TableField`

**什么时候需要它**

1. 属性名 ≠ 列名：`@TableField("car_num")`
2. 属性名与数据库**关键字冲突**：`@TableField("`desc`")`、`@TableField("`time`")`（要加反引号）
3. 属性**不是表字段**（比如 `serialVersionUID`）：`@TableField(exist = false)`
4. 需要自定义类型处理器：`@TableField(typeHandler = JacksonTypeHandler.class)`
5. 想让某字段**不参与查询**：`@TableField(select = false)`

> 属性名以 `is` 开头的布尔字段（如 `isVip`）在 **3.4.0 之前**必须写 `@TableField`，
> **3.4.0 起** MP 已自动处理，无需再加。但列名如果是 `is_vip` 而属性是 `isVip`，
> 建议还是显式写 `@TableField("is_vip")`，避免歧义。

**示例**

```sql
create table t_customer(
  id bigint primary key auto_increment,
  username varchar(255),
  is_vip varchar(255),
  `desc` varchar(255)
);
```

```java
@Data
@TableName("t_customer")
public class Customer {
    @TableId(type = IdType.AUTO)
    private Long id;
    private String username;
    @TableField("is_vip")
    private String isVip;
    @TableField("`desc`")   // desc 是关键字，必须转义
    private String desc;
    @TableField(exist = false)
    private String tempField;   // 表里没有这个字段
}
```

## 5. 常用配置

```yaml
mybatis-plus:
  configuration:
    map-underscore-to-camel-case: true      # 驼峰映射（默认 true）
    cache-enabled: false                    # 二级缓存（默认 true，一般关掉）
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl   # 打印 SQL（默认不打印）

  type-aliases-package: com.jkweilai.mp.model   # 别名包（默认不设置）

  mapper-locations: "classpath*:/mapper/**/*.xml"   # XML 位置（默认值就是它）

  global-config:
    db-config:
      id-type: auto                 # 主键策略（默认 ASSIGN_ID）
      update-strategy: not_null     # 更新策略：字段为 null 不更新（默认）
      insert-strategy: not_null     # 插入策略
```

**两个常见疑问**

1. **「MP 不用写 XML，为什么还要配 `mapper-locations`？」**
   单表 CRUD 不需要 XML；但**自定义 SQL、多表关联**时还是要写 XML，所以要配扫描路径。
2. **`classpath:` 和 `classpath*:` 的区别？**
   `classpath*:` 的星号表示「**跨模块/跨 JAR** 扫描所有 classpath」，适合多模块项目；
   代价是**效率较低**，不要滥用。默认值 `classpath*:/mapper/**/*.xml` 已经能覆盖大多数情况。

## 6. 本篇踩坑清单

| 坑 | 说明 |
| --- | --- |
| 用了 `mybatis-plus-boot-starter` 配 Spring Boot 3 | 必须换 `mybatis-plus-spring-boot3-starter` |
| 忘了 `@MapperScan` / `@Mapper` | 启动报 `A component required a bean of type 'xxxMapper' could not be found` |
| 实体名与表名不一致 | `Car` 默认找 `car` 表，实际是 `t_car`，必须 `@TableName` |
| 主键插入后没有 id | 默认 `ASSIGN_ID` 会自己生成；若想要数据库自增，配 `IdType.AUTO` |
| `updateById` 把字段更新成了 null | 默认 `update-strategy: not_null`，**null 字段不参与更新**，想置空要用 `UpdateWrapper.set("col", null)` |
| 关键字列名报 SQL 语法错误 | `desc`、`time`、`order` 等必须 `@TableField("`desc`")` |
