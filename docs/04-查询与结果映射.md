# 04 查询与结果映射

> 查询是 MyBatis 用得最多的地方。本篇把「返回值怎么给」和「结果怎么映射」讲透。

## 1. 返回一条：`Car`

```xml
<select id="selectById" resultType="Car">
    select * from t_car where id = #{id}
</select>
```

```java
Car selectById(Long id);
```

- `resultType` 写**每行**要封装的类型，不是 `List<Car>`。
- 查不到返回 `null`；查到多条抛 `TooManyResultsException`。

**最常见的报错**

```text
### Error querying database. Cause: org.apache.ibatis.executor.ExecutorException:
A query was run and no Result Maps were found for the Mapped Statement 'xxx.selectById'.
It's likely that neither a Result Type nor a Result Map was specified.
```

⇒ **忘了写 `resultType`**（或写成了空字符串）。

## 2. 返回多条：`List<Car>`

```xml
<select id="selectAll" resultType="Car">
    select * from t_car
</select>
```

```java
List<Car> selectAll();
```

- XML 里 `resultType` 依然是**单个元素的类型** `Car`，**不要写 `java.util.List`**！
- 返回类型由 **Mapper 接口方法的返回值** 决定。

## 3. 返回 Map

### 3.1 返回一条记录为 `Map<String,Object>`

场景：不知道表有哪些列（比如做通用的报表查询）。

```xml
<select id="selectByIdReturnMap" resultType="map">
    select * from t_car where id = #{id}
</select>
```

```java
Map<String, Object> selectByIdReturnMap(Long id);
```

结果形如：`{id=1, car_num=1001, brand=宝马520Li, guide_price=10.00, ...}`
**key 是列名**（不是属性名），所以 `car_num` 不会变成 `carNum`。

### 3.2 返回多条：`List<Map<String,Object>>`

```xml
<select id="selectAllReturnListMap" resultType="map">
    select * from t_car
</select>
```

```java
List<Map<String, Object>> selectAllReturnListMap();
```

### 3.3 返回 `Map<String, Map<String,Object>>`：用 `@MapKey`

需求：把 id 当 key，整行数据当 value。

```java
@MapKey("id")   // 用结果中的哪一列作为大 Map 的 key
Map<String, Map<String, Object>> selectAllReturnMapMap();
```

```xml
<select id="selectAllReturnMapMap" resultType="map">
    select * from t_car
</select>
```

结果：`{1={id=1, brand=...}, 2={id=2, brand=...}}`

> `@MapKey` 里写的是**结果集的列名**（别名也算），写错会报 `The column ... was not found`。

## 4. `resultMap` 结果映射

### 4.1 问题：列名和属性名对不上

表：`car_num`、`guide_price`、`produce_time`、`car_type`
实体：`carNum`、`guidePrice`、`produceTime`、`carType`

直接 `resultType="Car"` 的结果：**只有 `id`、`brand` 有值，其余全是 `null`**。
因为 MyBatis 默认按「列名 == 属性名」精确匹配。

### 4.2 解决方式一：SQL 起别名（简单场景够用）

```xml
<select id="selectById" resultType="Car">
    select
        id,
        car_num      as carNum,
        brand,
        guide_price  as guidePrice,
        produce_time as produceTime,
        car_type     as carType
    from t_car where id = #{id}
</select>
```

### 4.3 解决方式二：`resultMap`（推荐，可复用）

```xml
<resultMap id="carResultMap" type="Car">
    <!-- 主键用 id 标签，其余用 result -->
    <id property="id" column="id"/>
    <result property="carNum"     column="car_num"/>
    <result property="brand"      column="brand"/>
    <result property="guidePrice" column="guide_price"/>
    <result property="produceTime" column="produce_time"/>
    <result property="carType"    column="car_type"/>
</resultMap>

<select id="selectById" resultMap="carResultMap">
    select * from t_car where id = #{id}
</select>
```

- `property`：Java 属性名；`column`：SQL 列名（或列别名）。
- 用 `resultMap` 后**不要**再写 `resultType`。
- `id` 标签不只是「标记主键」：MyBatis 用它做**行唯一性判断**，在嵌套映射（一对多）里少写 `id` 会导致数据被错误合并、性能下降。

### 4.4 解决方式三：开启驼峰命名自动映射（最省事）

```xml
<settings>
    <setting name="mapUnderscoreToCamelCase" value="true"/>
</settings>
```

开启后 `car_num` → `carNum`、`produce_time` → `produceTime` **自动完成**，`resultType="Car"` 直接可用。

> Spring Boot / MP 里这个配置**默认就是 true**；原生 MyBatis **默认 false**。
> 驼峰映射只能解决「下划线 ↔ 驼峰」这一种情况，遇到 `cname → name` 这种还得用 `resultMap`。

## 5. 返回总记录数

```xml
<select id="selectCount" resultType="int">
    select count(*) from t_car
</select>
```

```java
int selectCount();        // 或 long selectCount();
```

- `resultType` 可以是 `int`、`long`、`java.lang.Integer`、`java.lang.Long`。
- 常用语：`select count(*) from t_car where ...`

## 6. `resultType` vs `resultMap` 怎么选

| | `resultType` | `resultMap` |
| --- | --- | --- |
| 适用 | 列名与属性名一致（或开了驼峰） | 列名与属性名不一致、需要自定义类型转换、嵌套映射 |
| 写法量 | 少 | 多，但**可复用** |
| 底层 | MyBatis 会自动生成一个隐式 `resultMap` | 你显式定义的 `resultMap` |
| 建议 | 单表标准字段 | 多表关联、字段名差异大、需要 `<association>`/`<collection>` |

**一句话**：一对一/单表用驼峰 + `resultType`，多表/复杂映射用 `resultMap`。
